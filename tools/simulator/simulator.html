LED panel simulator 64×32

Game controller:

Keyboard (outside the editor): ← → animation · B brightness · T tilt (landscape / portrait gallery) · Space pause · . next frame · Q D turn · S button


    
The animation restarts by itself when you stop typing (or Ctrl+Enter). Everything is saved in the browser.

    
Community examples (fan art and the like) are not shipped here: Open… loads them from a .json file you pick on your computer, nothing is fetched online.

    

      Available functions

Each animation defines   function anim(f, init) { ... }
  f     frame number: 0, 1, 2... (60 frames per second)
  init  true on the first frame (animation change, tilt, restart)
Variables declared OUTSIDE anim() keep their value from one frame to the next
(like "static" variables in the ESP32 code).

Drawing
  display.clearScreen()                  display.fillScreen(c)
  display.drawPixel(x, y, c)
  display.drawLine(x0, y0, x1, y1, c)
  display.drawFastHLine(x, y, length, c)
  display.drawFastVLine(x, y, length, c)
  display.drawRect(x, y, w, h, c)        display.fillRect(x, y, w, h, c)
  display.drawCircle(x, y, r, c)         display.fillCircle(x, y, r, c)
  display.drawTriangle(x0, y0, x1, y1, x2, y2, c)

Text (the panel's 5×7 font, 6 px per character)
  display.setCursor(x, y)     display.setTextColor(c)
  display.setTextSize(n)      display.setTextWrap(false)
  display.print(text)

Colours
  color565(r, g, b)    BLACK    WHITE
  colorWheel(0..255)   rainbow
  fireColor(0..255)    black → red → yellow → white

Maths
  W()  H()             width and height (64×32, or 32×64 in portrait)
  random(min, max)     integer from min to max-1
  int(x)               integer part, like (int)x in C++
  sin cos sqrt abs min max floor constrain map PI millis()
  sinTab[0..255]       precomputed sine, values 0..255

Mascot (Nimbus)
  drawMascot(x, y, size, { gaze, eyes, legs, armL, armR, squash })
    eyes : EYES_OPEN, EYES_CLOSED, EYES_HAPPY, EYES_KO
    gaze : -1, 0, 1         legs : 0, 1, 2         arms : 5 = rest, -1 = raised
  drawDroid(...)  drawLiquid(...)   the other mascots, same poses
  isBlinking(f, state)     state = { next: 90 }, true during a blink
  drawBubble(xCenter, y, "Hi!", colour)

Controller (games)
  encoder()    detents turned since the last frame (Q and D keys)
  button()     true if the button was pressed (S key)

Careful: in C++, 7 / 2 between two integers gives 3. Here 7 / 2 gives 3.5.
Write int(7 / 2) to get the same result as on the ESP32.

Older names (couleurFeu, clignement, bulle...) still
work, so animations written before the translation keep running.

To put an animation on the ESP32: convert it to C++
and add it to the gallery.
